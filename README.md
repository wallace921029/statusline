# AI Statusline Configurations

This repository collects custom statusline configurations for AI-powered coding assistants, showing real-time usage metrics directly in your terminal.

Each directory contains a ready-to-use statusline setup for a specific tool:

- [`agy/`](agy/README.md) — Statusline for [AntiGravity](https://antigravity.google/) / Google Gemini, displaying model info, effort level, context usage, and rate-limit windows.
- [`claude/`](claude/README.md) — Statusline for [Claude Code](https://code.claude.com/), showing model, effort level, context usage, and reset times.

For setup instructions, refer to the official documentation linked in each subdirectory.
